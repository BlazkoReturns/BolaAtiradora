## Comentários didáticos sobre o pygame

Este projeto é usado para aprender pygame. Em todo código escrito ou alterado:

- Comente em português cada função, classe, método ou constante do pygame usada
  (ex.: `pygame.init()`, `display.set_mode()`, `event.get()`, `draw.circle()`, `Clock.tick()`),
  explicando o que ela faz e o significado dos parâmetros relevantes.
- Ao usar um recurso do pygame pela primeira vez no projeto (sprites, sons, imagens, colisões etc.),
  explique também o conceito por trás dele.
- Código Python comum (fora do pygame) só precisa de comentários quando não for óbvio.
